# Integration logos

These logos identify the servers and services in Opscode's Plugins page. Each one is the trademark of its owner and is
used only to show which service a tile connects to. Opscode is not affiliated with or endorsed by any of them.

Where each file came from (checked 2026-11-17):

- github.svg, notion.svg, figma.svg (colour), huggingface.svg (colour), firecrawl.svg (colour), mcp.svg: @lobehub/icons-static-svg 1.103.0 (MIT), https://lobehub.com/icons
- supabase.svg, sentry.svg, zoho.svg, hostinger.svg: simple-icons 16.38.0 (CC0-1.0), https://simpleicons.org, filled with the brand colour from its data file
- playwright.svg: the Playwright logo from https://playwright.dev/img/playwright-logo.svg (Microsoft)
- context7.svg: the square mark of the Context7 logo from https://context7.com (Upstash), cropped from its logo file
- tinyfish.svg: the fish mark of the TinyFish logo from https://www.tinyfish.ai/TF-Logos/Horizontal%20Logo/SVG/TF_Horizontal.svg, cropped to the fish
- chrome-devtools.svg: "Google Chrome icon (February 2022)", Google, https://commons.wikimedia.org/wiki/File:Google_Chrome_icon_(February_2022).svg (shown for Chrome DevTools)

None of the files contains a script or an external link (checked).

Added 2026-11-17 for the sign-in (OAuth) servers:

- linear.svg, stripe.svg, atlassian.svg, cloudflare.svg, neon.svg, posthog.svg, vercel.svg: simple-icons (CC0-1.0), https://simpleicons.org, filled with the brand colour. Marks belong to their owners and follow each owner's brand guidelines.
- monday.svg: the monday.com mark from the monday.com brand page (monday.com brand guidelines).
